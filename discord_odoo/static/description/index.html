Odoo 19.0

Discord Odoo Integration

Send Odoo notifications to Discord through a standard incoming webhook. Configure it from Settings, test it instantly, and optionally reuse the mixin in your own business models.

Key Features

  • Discord webhook settings in Odoo General Settings
  • One-click test message from the Settings screen
  • Opt-in mixin for create/write notifications
  • Supports plain text and embed payloads
  • Unicode-safe messages, including Burmese text

How It Works

  1. Create an incoming Discord webhook for the target channel.
  2. Paste the webhook URL into Odoo Settings.
  3. Enable the integration and save.
  4. Click Send Test Message to verify delivery.

Developer Usage

To send notifications from a custom model, inherit from discord.notify.mixin.

Example: 

from odoo import models

class SaleOrder(models.Model):
    _inherit = ["sale.order", "discord.notify.mixin"]

Compatibility

  • Odoo 19.0
  • Standard Discord incoming webhooks
  • No bot token required
  • No external JavaScript
